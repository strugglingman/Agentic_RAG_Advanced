# Reports

This directory stores generated analysis and audit reports for this repository.

## Purpose

These reports help with:

- documentation drift checks
- system health checks
- retrieval / RAG evaluation summaries
- browser / UI smoke test summaries
- other temporary engineering audits

## Notes

- Most report files in this directory are generated artifacts
- Generated reports usually should **not** be committed to git
- Keep only this README and any intentional template files under version control

## Typical Files

Examples of report filenames:

- `docs-drift-report.md`
- `health-report.md`
- `rag-eval-report.md`
- `ui-smoke-report.md`
